# ESP32-S3 Internet Monitor

A MicroPython project for an ESP32-S3 that watches internet connectivity, detects outages, and can power-cycle a connected router when the upstream connection is down.

## Features

- Wi-Fi connection management with DHCP or static IP support
- Periodic connectivity checks against public IP endpoints
- Automatic router power cycling via a relay
- OLED status display for runtime diagnostics
- Local activity logging for troubleshooting

## Hardware

This project is designed for an ESP32-S3 board with:

- SH1107 128x128 OLED display on I2C
- relay module connected to GPIO 6
- momentary button on GPIO 7 for display wake-up
- router power control through the relay board

## Quick start

1. Copy `config.example.py` to `config.py`.
2. Update the Wi-Fi, static network, and timezone values in `config.py`.
3. Copy the project files to your MicroPython device:
   - `main.py`
   - `config.py`
   - `sh1107.py`
4. Run `main.py` on the board.

## Project files

- `main.py` — main monitoring logic and device setup
- `config.example.py` — template for local configuration values
- `sh1107.py` — OLED driver
- `activity.log` — runtime log file generated by the monitor

## Notes

- `config.py` is intentionally ignored by Git so Wi-Fi credentials stay local.
- `config.example.py` is the safe version to commit and share publicly.
